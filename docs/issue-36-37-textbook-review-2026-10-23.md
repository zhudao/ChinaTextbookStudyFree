正文修正了只看目录可能产生的误判：

- **“倍”仍在。** p13 两步问题要求先求一个中间数量，再求其倍数；p93 复习继续使用这一数量关系。因此“倍的认识”失去独立单元，不等于相关题目全部废弃。
- **“吨”仍在。** p32—35 的称重活动明确涉及克、千克、吨及换算，应从旧“测量”归入实践活动。
- “线和角”有圆规比较线段等要求（p63—64），而 p71 知识结构图没有把量角器读数作为本单元目标。从旧四上复制时要裁剪深度。
- 旧“时分秒”“万以内加减法”“长正方形周长”“集合重叠问题”不再分别作为本册独立主单元；零散背景知识或复习情境仍可出现，不能据此恢复整组旧课程。

官方目录为“天气”“水”“物体的运动”，每单元 8 课，共 24 课，与 issue 一致。

- **天气：** 从旧上册第 3 单元审核迁到新第 1 单元。气温计、测温、雨量、风、云有旧知识可用；补“我们关心天气”和天气影响等目标。新版 p20—22 重点是读取、比较观测记录和预报信息，不应把旧“天气预报制作流程”直接当作同一个课节。
- **水：** 旧第 1 单元内容迁到新第 2 单元，按 8 课拆分。新版“水珠从哪里来”需要覆盖凝结；冻结与熔化分为独立课，不能用旧合并知识点的数量证明已覆盖。旧蒸发、沸腾、溶解与分离题可逐项审核。
- **运动：** 对本册是新单元，但仓库旧三下第 1 单元已有位置、参照物、运动轨迹、比较快慢等题；旧四上“运动和力”也有能量相关内容。应先找候选，再按新三上水平审核，避免全部重新生成。

## 题库迁移与工程结论

五册基线的源题统计如下。常规题来自 `unit_test.questions`，不含单元挑战题；“题库知识点组”按单元分别去重，且不等于人工审核通过课数。

| 教材 | 大纲知识点 | 题库知识点组 | 常规源题 |
| --- | ---: | ---: | ---: |
| 二上语文 | 27 | 57 | 374 |
| 三上数学 | 32 | 32 | 246 |
| 三上语文 | 24 | 92 | 569 |
| 三上英语 | 19 | 55 | 356 |
| 三上科学 | 17 | 38 | 229 |
| 合计 | 119 | 274 | 1,774 |

`build-data.ts` 会把题库中未在大纲列出的知识点追加为课节。后续审核必须枚举 **274 个现有单元知识点组**，不能只核对大纲里的 119 个知识点。例：三上语文同时存在“阅读中的新鲜感词句”和“阅项中的新鲜感词句”两个键，不能原样复制后把多出的课节当作覆盖成果。本次未修改这些旧数据。

建议实施顺序：

1. 固定上述官方资源及哈希，建立五册的新目录、正课/园地/例文/选学项目清单和旧内容候选映射。新版语文、英语的全文需从原页逐句校勘，OCR 不直接导入生产。
2. 补全版本化的课文抽取与原页渲染输入。现有 `extract_passages.py` 从文件名生成旧 bookId、默认读旧 PDF 批次；`render_pages.py` 默认寻找旧 PDF 目录，需要显式接收版本与来源。
3. 接通生成暂存与前端构建：`scripts/quiz/pipeline.py --edition-config` 输出到 `output/editions/<id>/...`，而 `build-data.ts` 读取 `output/<subject>/...`。新增一个显式审核导入步骤，或为构建器增加版本来源配置；不要让“生成成功”被误认为“已发布”。
4. 按新版知识点逐题审核候选，保持旧版全部 ID 和内容；新版书、课文、课节使用独立 ID。更新正文导致文本变化的音频才补生成，原页映射重新生成；单元故事另行核对，不能继承旧单元号假装配套。
5. 验收五册新版的目录、正文栏目、题目/讲解覆盖与实际判分，同时跑旧内容保留检查。Web、iOS 资源下载/种子、Release、Docker 与线上部署要分别验证，不能只在源码目录验收。

这次仅新增核对记录和证据清单，未改学习内容、成绩、音频、发布包或 GitHub issue 状态。
