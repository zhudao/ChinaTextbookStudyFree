# Issue #36 / #37：五册新版教材更新与验证

## 更新范围

依据[核对报告](issue-36-37-textbook-review-2026-10-23.md)和国家中小学智慧教育平台的公开教材页，新增下列独立版本；不改写旧版教材文件或旧版学习记录的键。

| 教材 | 新版 ID | 保留旧版 ID |
|---|---|---|
| 数学三年级上册（人教版） | `g3up-2026` | `g3up` |
| 语文二年级上册（人教版） | `chinese-g2up-2026` | `chinese-g2up` |
| 语文三年级上册（人教版） | `chinese-g3up-2026` | `chinese-g3up` |
| 英语三年级上册（人教 PEP） | `english-g3up-2026` | `english-g3up` |
| 科学三年级上册（教科版） | `science-g3up-2026` | `science-g3up` |

五册合计 35 个单元/实践活动、150 个练习课时、900 道课时题及 210 道单元挑战题、118 篇/组朗读内容。全站共 50 册版本，其中 44 册为当前版本，6 册为保留旧版（包含此前已更新的二上数学旧版）。

三上数学的两个实践活动按教材顺序穿插，使用单独单元编号 101、102，界面显示“综合与实践”；跳级前置课程按教材顺序判断。语文和英语保留正课、园地、习作例文、选学及复习内容的区别。朗读页码直接对应已校验的官方页图。

## 旧版和成绩

新版教材、课时、单元挑战、宝箱及朗读均使用独立 ID。旧版文件和路由继续保留。默认年级书单显示当前版本；Web 的教材切换菜单保留历史教材，iOS 开启“显示旧版教材”可访问历史教材；已选择旧版的用户可以继续使用旧版。此次不迁移或重置浏览器/iOS 中保存的旧成绩。

构建前保存所有旧版教材 JSON 的去音频版本指纹，构建后逐文件对比。音频地址的缓存版本参数及 `generatedAt` 不属于教材正文身份。另运行真实进度存储的多用户、迁移、奖励、阅读和续做回归，以验证旧记录兼容性。

## 内容和资源来源

[目录](../content/editions/2026/catalog.json)固定新版的知识点、课文、课号和页码。[资源证据清单](../content/editions/2026/resource-manifest.json)记录候选内容指纹、官方页图 SHA-256、逐篇图片核对和修订说明。全部题目经过独立模型复核；额外检查中，将英语第六单元四道纯中文计算题改为英语情境与英文数量/价钱表达，并再次复核；选择题按题面和选项指纹稳定打散顺序，避免正确答案集中在首项；118 篇/组朗读逐一与官方页图核对。这里的复核是模型编辑检查，不代表教师审定。

原始课文来源和教材页图沿用项目约定，放在忽略的 `data/passages` 和 `apps/web/public/textbook-pages` 中，随资源包分发。运行 `scripts/editions/materialize_2026.py` 时，必须提供完整且通过复核的候选目录及已校验的官方页图缓存。脚本先验证整批数据，再写入新版路径；缺失新版朗读来源时，Web 构建会明确失败。

首次 v1.5.0 发布的新增音频使用 macOS Tingting（中文）和 Samantha（英文）离线合成。后续用户试听要求改回 Edge；v1.6.0 将这五册与五上语文一起重做，采用按教材版本隔离的音频地址，保留旧版、原有成绩和历史兼容资源。详见[五上语文与 Edge 音频重做记录](issue-22-textbook-review-2026-10-24.md)。

## 本地构建及安装

本次资源为五册教材的源码资源增量覆盖包（仅支持 source 模式，安装后需重新构建站点），依赖现有完整基础资源，不能当作空目录的完整安装包。安装器会核对全部旧版基础教材数据，发现缺失或本地改写时在写入前停止。使用完整基础资源和本次资源包后再执行 `npm run build`。

```sh
python3 scripts/install-release.py --tag v1.5.0-five-textbooks \
  --archives-dir release-assets/2026-five-textbooks --root .
npm run build
```

可直接用已验证的静态站点制作 Docker 镜像：

```sh
docker build --target prebuilt --build-context site=./apps/web/out \
  -t cstf:2026-five-textbooks .
```

以上记录发布前的本地五册增量包验证。正式发布已改用可全新安装的完整 `v1.5.0-five-textbooks` 资源包，Docker 与源码默认资源版本、iOS 下载地址均已同步更新；全部 50 册 iOS 包配套提供，历史版本继续保留。线上已更新并完成成绩兼容验收，详见[发布报告](five-textbooks-release-2026-10-24.md)。
