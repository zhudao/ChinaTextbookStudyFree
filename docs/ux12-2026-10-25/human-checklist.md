使用 [线上网站](https://d3nmsqi4n72idj.cloudfront.net/)，在“我的 → 添加孩子”创建测试档案，保留日常档案。所有项目尚未开始；自动测试、模型复核和模拟视口不作为通过记录。

## 1. 教师语义与朗读（UX-02 / 05）

请对应学科教师按 [137课队列](teacher-queue.md) 分批核对。先看四上 `g4up-u1-kp1` 题15、五上 `g5up-u4-kp3` 题26，以及 [12处修正](../ux-content-corrections.json)。

- 根据题干独立作答，检查前提是否齐全、是否只有一个正确答案、解析推导是否成立、语言是否适龄。
- 逐项听题目、选项和解析；特别留意汉字多音字、英语重音及数学符号。
- 回填“课时ID / 题号 / 语义通过或需改 / 朗读通过或需改 / 修改建议”。完整队列全部签审前不勾选完成；这也不等于全站题库审核完成。

## 2. 儿童15分钟试用（UX-06 / 07 / 11 / 12）

一年级学生使用测试档案，先按真实默认路径“一年级 → 数学一年级上册（2022课标修订版）→ 在校园和教室里发现数学”进入 [当前首课](https://d3nmsqi4n72idj.cloudfront.net/lesson/g1up-2026/g1up-2026-u101-kp1/)。另用 [点苹果示范课](https://d3nmsqi4n72idj.cloudfront.net/lesson/g1up/g1up-u1-kp1/) 做对照，两条路径分开记录；不能用旧版示范课的结果替代当前默认首课。家长观察，不指点答案。

1. 两条路径各从“开始”计时，到孩子第一次自主数物体、判断位置或作答；仅点“下一步/跳过讲解”不计学习动作。记录秒数，目标30秒内；同时记录是否使用跳过讲解、是否需要提示、第一次犹豫在哪里。
2. 让孩子自然作答并完成纠错；不要求故意答错或强行在15分钟内通关。全对时将纠错理解记为待测，不能推定已理解。结算后询问：“第一次答对几题？后来改对几题？下次想再练什么？”记录孩子原话，不把成人解释后重复当作理解。
3. 分别试退出、保存、朗读、设置和下一课，记录是否点到相邻控件、是否需成人帮助。辅助按钮软件尺寸已检查，仍需实际拇指操作。
4. 展示学习、手册、课文、故事、错题、商店等页面，问“聪聪会怎样帮你学习？”记录孩子能否说出具体帮助。成人按10页检查记录核对语气和角色一致性，儿童理解另记。

## 3. 真机与真实弱网（兼顾 #3）

|设备|操作|反馈记录|
|---|---|---|
|日常手机 Safari 或 Chrome|竖屏/横屏；答案选中刷新；已检查反馈刷新；后台切回；试听/暂停；继续下一课|机型、系统、浏览器版本，是否恢复原阶段、重复扣心、声音异常或误触|
|iPad 6（若有）|记录系统/浏览器版本；首次加载、进入课时、下载/播放；横竖屏；后台恢复|具体停在哪一步、等待多久、可见错误；此项同时补 #3 的真实设备证据|
|手机真实移动网络|开始加载时断网，等失败提示后恢复网络并重试；播放中断网再恢复|是否可重试、是否误记完成/奖励、进度和旧成绩是否保留|

受控本地 HTTP 失败/延迟测试与上述真机弱网分开记录。没有对应设备时写“未测”，不要填通过。

## 4. 延迟掌握（UX-05）

同一测试学生在次日及第7天做数数示范单元的新情境题，不给答案提示、不重复背原题；记录独立首答、用提示情况和可解释的理由。今天通关及题量增加都不足以证明隔天仍会。

## 最简反馈模板

`日期 / 设备系统浏览器 / 页面或课时ID和题号 / 操作步骤 / 等待秒数或误触次数 / 预期 / 实际 / 孩子原话（可选）`

只需文字和必要截图，不需要学生真实姓名、录音或账号资料。以上结果回来后再更新 #12 对应验收；追踪定时任务继续暂停。
