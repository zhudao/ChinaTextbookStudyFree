## 原因及对先前验收的更正

已补齐内容保存在 v1.4.0 的发布快照与本地题库改动中，当前 `main` 没有带入这批完整题库。随后 v1.4.2 使用主线 `output/` 重建数据，因此生成了较早的题库规模。此前 [PR 24 资源恢复记录](pr24-resource-restoration.md) 也明确使用 PR 自身题库、不合并 Release 快照题库。

本次发布验证了当前输入的文件、哈希、音频和页面可用性，却漏掉了“已补齐题目和讲解跨版本保留”的核对。Docker 升级成功只证明容器启动、音频与测试流程成功，不能据此认定旧版的 15,117 道题全部保留。

README 先前将 1,474 / 1,174 概括成“尚未补齐”，遗漏了已经生成、导入并发布的成果；现更正为**题库版本衔接缺陷**。[当前覆盖审计](content-audit-2026-10-21.md) 的数值仍是本次发布包的真实数值，但不代表之前没有补齐。

## 修复所需工作

应恢复已发布、已有验收记录的补齐题库，合并当前主线的 2026 秋版二上数学、示范课和后续明确纠错，保留课程及题目 ID。无需因这次衔接错误重新调用 GPT Luna 生成同一批内容。

恢复后需重新构建，逐课核对补齐覆盖、ID、判分与语音文本，给新增或变化的文本补齐对应 Edge 音频，再重新部署、打包和验证 Docker 升级。在这些工作完成前，v1.4.2 不应被作为已补齐题库的完整升级；已有完整题库的部署应保留原材料与备份。本页记录的是已确认的问题与恢复依据，尚未宣告恢复完成。

题目数量和讲解对象齐备不等于教学语义全部正确；真实教师签审仍是独立待办。
