# #26：多孩子学习档案

基于 `origin/main` 278aa81（2026-10-19，最新熊猫版 Web），在「我的 → 学习档案」添加孩子、修改名字及切换。新档案从年级选择开始，旧记录沿用原来的存储键，归入默认档案。

各档案分别保存完整进度（含数感、任务、联赛、收藏、报错、成就及阅读）、未完成课程、错题、奖励、家长设置、主题，以及复习、故事和数感检验的临时会话。切换通过完整导航重置组件和播放状态；sessionStorage 可用时，已打开的标签页保持自己的档案。深色模式的首屏脚本与存储使用同一个档案。

范围是 Web 本地档案，可使用原有的存档导入导出功能迁移单个孩子的记录；不新增密码登录或云端同步，也未修改 iOS 原生端。清除浏览器数据会删除本地档案。

验证：类型检查、`scripts/checks/learner-profiles.ts`、核心 231 项测试、learning-quality 和 visual-controls 检查均通过。浏览器在最新熊猫界面实际创建「姐姐／弟弟」并切换。测试覆盖旧数据迁移、切回恢复、阅读／复习／数感临时会话隔离和首屏主题一致性。
