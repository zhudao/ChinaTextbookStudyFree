# #14：一年级语文拼音朗读修复

跟进 [2026-10-25 的反馈](https://github.com/wuwangzhang1216/congcong-school/issues/14#issuecomment-6407725012)。原数学教材更新已于 v1.7.0 完成；本次处理新反馈中的一年级拼音朗读问题。已随 [v1.7.2](https://github.com/wuwangzhang1216/congcong-school/releases/tag/v1.7.2) 上线；[完整验收记录](final-acceptance.json)。Web 及资源源提交固定为 `950854a5eb8bc89f360ccc8ec096fa0859c8d9cb`，后续仅补充验收文档及发布元数据。

## 原因和修复

原采集器把不含汉字的 ASCII 拼音判为英语，例如 `a`、`b`、`an`、`eng`、`yi`；语文与英语还共用按文本生成的音频地址，因此只改音色无法排除已缓存的英语音频。原先纯带调元音还可能因不含 ASCII 字母而被过滤。

一年级语文上下册现在使用共享的拼音朗读规则。声母用教学呼读音，能可靠对应的音节采用同音汉字引导 Edge，轻声词“喇叭”“衣服”单独处理，错误拼写选项明确拼读。Edge 会吞掉部分带调字母，四声选项曾实际只生成一个元音。因此对 55 条涉及四声或特殊音节的录音，使用 Edge 中文声音素材和本地 Praat PSOLA 控制声调；对 eng、ong 等从对应音节的韵母部分取音，保留正确的韵母。其余 382 条直接保留 Edge 合成流。四组四声选项在 MP3 和 iOS AAC 中均检查到 16 个完整元音，实际声调曲线及排列符合预期。规则不改变展示文本或作答答案。Python 采集器与 TypeScript 构建器通过实际题库差分测试保持一致。

新音频地址包含原文本、语文拼音语境、朗读计划、音色及语速的指纹，以 `.pinyin-…` 区分。找不到新版音频时不退回原来的英语字母文件。英语及其他年级保持原地址和音频字节。使用免费 Edge `zh-CN-XiaoxiaoNeural`，语速 `-10%`，没有付费 TTS/模型调用。音频不是人教社官方录音。

生成 437 条拼音专用音频；386 条出现在当前发布内容的 473 个朗读位置，另外 51 条覆盖未被当前课时抽取的源题。另补齐三条普通中文音频。直接生成的 382 条拼音及三条普通中文 MP3 保留 Edge 原始字节；55 条本地处理音频明确记录渲染方式。提供真实 Ogg/Opus 与 iOS AAC 格式；不以错误扩展名发布 provider MP3。

## 同单元的确定性题目修正

[完整前后对照](content-fixes.json) 保留原题及修正理由：

- 单元练习 #18：`p＋à` 对应“怕”，原题误判“跑”，并含不相符的“跑步”语境。
- 单元练习 #19：修正连线中的词语与答案排列，移除自相矛盾的解析。
- 源挑战题 #6：原题将没有语境的合法音节判为拼写错误；改为明确辨别 `u` 与 `ü`。
- 源挑战题 #12：原题没有声调参照却要求找错；改为明确判断汉字与拼音是否对应。

后两题没有被本版挑战课的固定抽题规则选中，线上挑战课内容不变。前两题进入 `chinese-g1up-u3-kp2`。教材、课时、题目 ID 均保留，已完成成绩不重新判分；只有该课未提交会话因内容指纹变化需要重开。纯音频更新不改变其他未提交练习的内容指纹。旧错题进入复习时会读取当前题目，保留原复习调度状态。
