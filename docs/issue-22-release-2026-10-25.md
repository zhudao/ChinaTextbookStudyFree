2026-10-25 已通过 [PR #39](https://github.com/wuwangzhang1216/ChinaTextbookStudyFree/pull/39) 合入主分支并上线。[新版五上语文](https://d3nmsqi4n72idj.cloudfront.net/book/chinese-g5up-2026/)与[旧版五上语文](https://d3nmsqi4n72idj.cloudfront.net/book/chinese-g5up/)同时保留，使用原 CloudFront 域名及原学习存储，不迁移或清空成绩。

## 音频

用户确认 Edge 试听后，本册与上一轮五册共 10,055 个“文本 + 音色”任务全部改用 Microsoft EdgeTTS：五上语文为晓伊，其他四册的中文与三上英语中文讲解为晓晓，英文为 Guy，语速 -5%。所有 MP3 完整解码，另生成匹配 Opus 与 iOS AAC/M4A。没有失败任务回退到本机配音。

新地址按六册版本映射，保留历史音频；未改音色的 45 册共 2,757 个 JSON 连音频地址完全不变，原有 3,812 项全局音频映射未改写。线上逐一下载全部 10,055 段当前 Edge MP3，SHA-256、MIME 与 `nosniff` 全部通过。
