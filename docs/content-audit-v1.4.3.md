## 防止再次回退

新增 [逐课内容基线](../release/content-baseline-v1.4.0.json) 与 [保留检查脚本](../scripts/checks/content-retention.py)，绑定原 Release 的 data.zip 校验和、课节 ID、题目 ID、题目与知识讲解指纹。当前构建、CI、打包、网站预备和 AWS 部署均执行检查。已用发生回退的 v1.4.2 数据进行反向测试，检查明确失败。

```sh
python3 scripts/checks/content-retention.py --public apps/web/out
npx tsx scripts/checks/content-grading.ts apps/web/out
python3 scripts/checks/site-integrity.py --public apps/web/out --site apps/web/out
```

上述命令不调用内容生成或在线 TTS；所需完整资源由修正版 Release 安装。

## 音频完整性

- 全材料包含 **249,852** 个音频文件：130,633 个兼容源路径、119,219 个 MP3。实际页面使用 102,082 个唯一 MP3 地址，缺失为 0。
- 复用已完成的音频，本轮以 Edge TTS **并发 4、每秒 2 次**补充 2,461 段，其中中文 56 段、英文 2,405 段。失败按全局限速和指数退避处理。
- 全部 111,675 条源文本及实际构建朗读字段均有音频。全部已知 4,685 个旧 GPT 来源音频逐一核对为已替换的 Edge SHA-256，兼容源路径和 MP3 同时核验。
- 所有音频内容有完整解码依据：本轮完整解码 93,771 份不同字节内容，其余 104,579 份与此前完整解码证书的 SHA-256 一致。解码失败为 0。
- Edge 对少数孤立拼音/声调符号返回空流时，保留原文本哈希和路径，使用同音汉字或明确的音标说明与例词合成，详见 [发音映射](edge-phonetic-pronunciations.json)。这不是逐条教师听审。
- 机器结果见 [音频审计](audio-integrity-v1.4.3.json)；每个发布文件的 SHA-256、分包清单和逐文件清单见 Release 的 `SHA256SUMS`、`manifest.json`、`files.jsonl`。
